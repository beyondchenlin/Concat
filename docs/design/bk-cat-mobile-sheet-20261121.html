浮动入口留在预览区域，原底部工具条继续承担剪辑操作。

  1. 点击浮动入口先展开半屏对话，保留上方画面。
  2. 拖动顶部横杠向上全屏，向下缩回；对话正文独立滚动。

  4. 返回原来位置面板不重建编辑器，保留片段选择与播放位置。
