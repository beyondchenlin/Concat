## 构建

`cargo test --locked --offline -p concat --lib -j 1`：284 通过，0 失败。格式检查及差异空白检查通过。Windows 上隔离程序需将实际 ONNX Runtime DLL 放在可执行文件旁；仅把该库目录加入 PATH 会先命中系统目录同名库。隔离副本补齐 DLL 后 `--version` 和 `--smoke` 均退出 0，实际启动的窗口和 WebView2 进入恢复核对状态。发布工作流已有将运行库复制到程序旁的步骤，本轮未验收安装包。
