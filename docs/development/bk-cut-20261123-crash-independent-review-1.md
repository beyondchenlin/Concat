# BK CUT（智能剪辑软件）整应用故障验收入口：第一轮独立代码审查

日期：2026-11-23。审查者：品牌与构建协作代理；实现者：原生工作流协作代理。操作回执模块由其他代理独立审查，本记录不把作者自查计为独立复审。

## 结论与边界

本轮审查提出七项验收判据及清理问题，修正稿已逐项复核关闭静态缺口。允许进入整合编译与真实运行阶段。本记录**不是**五状态应用进程异常终止验收通过证明，也不是安卓验收或真实模型供应商验收。

已实际执行：父驱动语法解析；分别通过解释器优化开关和优化环境变量启动入口，均在创建目录、应用进程、夹具与凭据之前退出，明确拒绝关闭验收断言。尚未执行：新故障模块编译、真实窗口十组强制终止与重启、真实截图目视检查、安卓整进程故障矩阵。

## 五个断点的实际位置

| 状态 | 正常生产路径中的阻断位置 | 终止前内存剪辑数 | 终止前磁盘剪辑数 | 回执、保存事实 |
| --- | --- | ---: | ---: | --- |
| 意图已落库、原生未执行 | 新意图准备成功后、原生提交前 | 0 | 0 | 无回执、无保存捕获 |
| 原生已执行、回执未落库 | 原生提交成功后、回执持久化前 | 1 | 0 | 无回执、无保存捕获 |
| 回执已落库、工程未保存 | 回执持久化成功后 | 1 | 0 | 有原回执、无保存证明 |
| 工程已保存、完成未送达 | 同一回执断点内调用真实保存队列，等精确版本证据落库 | 1 | 1 | 有原回执和保存证明，完成未确认 |
| 工程保存先到、回执后到 | 原生提交成功而回执尚未记录时调用真实保存队列 | 1 | 1 | 无回执，有独立持久保存文档捕获；操作结果仍未知 |

断点没有直接插入模拟操作行。流程从真实窗口回调发起明确请求，经过内置原版运行组件、原生批准、受控编辑、操作日志及真实有序保存队列。确定性模型夹具只绑定本机回环地址，不属于真实供应商推理验证。

父驱动等待已刷新的检查点后，针对自己启动且仍存活的完整应用进程执行系统强制终止，保存终止返回码和进程退出码，复制实际磁盘工程及日志，再以不同进程标识重新打开同一隔离工程。组件销毁、正常关闭或应用已自行退出都不能满足该断点判据。

## 发现与整改复核

| 编号 | 原判据缺口及影响 | 修正与复核结论 |
| --- | --- | --- |
| C01 | 重启后仅比较回执和保存字段是否存在，漏检先到保存捕获、状态及事实指纹；第五状态丢失证据仍能通过。处理后也没有强制确认复核已持久化。 | 现完整比较终止前后原操作集合；明确继续或放弃后要求原操作已核对，除此字段外全部原事实不变。第五状态还明确保持无原回执和非空保存捕获。静态关闭。 |
| C02 | 静默检查以启动完成后的请求计数作为新基线，启动阶段提前发出的请求被纳入基线。 | 选择前强制总请求数等于终止前的一次、恢复请求数为零，再观察额外静默窗口；人工选择前原生版本也必须不变。静态关闭。 |
| C03 | 仅凭出现零变更拒绝和剪辑数为零就宣称锁轨校验通过，其他拒绝原因也满足。 | 绑定新恢复调用及原会话，核对当前工程、原生会话、版本、明确的锁轨拒绝码与目标轨道；拒绝前后完整原生视图相同，随后才解锁并为新计划另行批准。静态关闭。 |
| C04 | 截图使用桌面图像并裁窗口矩形，未核实激活结果或遮挡，其他窗口的像素会被错误标为验收窗口。 | 现核验真实前景窗口、进程归属和客户区域，检查前方其他进程窗口的重叠区域；无法确认时拒收截图。真实运行时还需目视确认所存图像。静态关闭。 |
| C05 | 清理生成凭据时的超时异常会跳过夹具关闭及最终结果落盘。 | 现局部捕获清理异常，将该用例标为失败，记录准确清理参数与工作目录，继续关闭夹具并保存结果。不会清理其他凭据。静态关闭。 |
| C06 | 父驱动大量使用语言断言作为验收门禁，优化模式会移除断言。 | 入口在任何副作用前拒绝断言关闭状态。独立执行优化开关和优化环境变量两种入口，均退出 1 并报告断言关闭。已实际复核。 |
| C07 | 回环夹具仅检查授权头前缀，不能证明取到本次生成的正确系统凭据。 | 现以本用例非秘密标记中的摘要校验收到的凭据；日志与报告均不写授权头原值。静态关闭。 |

第五状态的继续路径按原生事实处理：保存文档存在不能证明旧操作成功。入口只接受明确的 `runtime.editUnverified`（剪辑结果未核实）稳定码作为该用例的预期拒绝，记录真实界面提示，等待旧宿主释放后沿既有入口重新取得只读核对；其他错误仍判失败。不能把模型的完成文字作为旧操作成功证明。

## 隔离、留存与运行门禁

每个状态与继续/放弃组合都创建新的隔离目录。已有目录拒绝覆盖；可移植目录必须首次为空。原始用户工程、模型服务配置与用户凭据不参与夹具。只生成本用例随机系统凭据，并在写入凭据前刷出非秘密清理身份；删除前核对原值摘要，值已变更则拒绝删除。

运行日志保留检查点、终止前后原生视图、磁盘内容摘要、原操作事实、原版任务持久状态、系统终止记录、真实窗口图像、请求计数、原始只读日志表和清理结果。单个失败用例不能以正常退出、组件重建、旧截图或模拟回执替代。

最终运行必须核验十个独立组合全部结束、所有用例通过、完整五乘二矩阵标志为真、每项凭据清理通过，并逐张目视核对真实截图。部分状态运行只证明所选子集。受控夹具通过不证明十一类供应商真实接通；桌面矩阵通过不证明安卓真机生命周期与整进程恢复通过。

独立脚本检查的机器可读记录位于本轮构建证据目录中的 `crash-driver-independent-review-checks.json`（脚本检查记录）。若审查后故障模块或父驱动摘要改变，须复核变更后再沿用本结论。
