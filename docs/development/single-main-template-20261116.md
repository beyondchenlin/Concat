# 单主轨类型化模板：实现与验证边界

## 已实现

现有 `edit_apply_guarded`（受保护批量编辑）接收顶层 `applySingleMainTemplate` 命令。计划包含 `start`、`videos`、`subtitles`、`overlays`、`music`、`voice` 六项。视频不可为空，其余空数组表示明确不添加该角色。

- 只操作当前**没有片段的活动时间线**；有旧片段时明确拒绝，不替换、不删除。
- 保留原有空轨，在事务内追加音乐、配音、主视频、字幕、贴片文字五条角色轨，所有轨道和片段 ID 由原生生成。
- 视频按照真实源区间连续排列。字幕和贴片保持独立文字，音乐和现成配音保持独立音频；线性音量明确为 0 至 1。
- 接续原有媒体实测、会话/版本、锁轨、操作日志、去重及一次撤销通路。一次撤销撤回新增轨道和片段，重做恢复同样 ID。
- 禁止任意路径、调用者提供新轨 ID、嵌套模板、普通自动建轨和隐式导入。
- 数量上限为 `MAX_BATCH_OPERATIONS - 1 = 1023`；非法时间、超源范围、同角色重叠及超主片时长均拒绝。最多一纳秒的二进制浮点舍入误差被规范化，不做帧级移位或自动寻找空隙。
- 文字样式严格保真：包括背景度量和嵌套 runs 的所有数值须有限；任何会被原生 tidy 修正的样式直接拒绝，不默默裁剪字体、透明度、背景或文字范围。颜色必须符合渲染器的六/八位十六进制格式（背景可为空）。模板专用解码拒绝非法 align、textCase 和 runs，保留合法缺省；旧命令及项目恢复解码行为保持不变。
- 不扩大色彩元数据授权。首次 HDR 素材会触发 SDR 时间线色彩变化时，现有保护仍拒绝整次计划，无部分写入。

## 验证

2026-11-16，固定 Rust 1.93.1（显式 bootstrap cargo/rustc）、本地离线 `concat-project` 完整库测试（启用 schema）：242 项通过、0 失败。新增十组测试覆盖五角色及层级、序列化保存重开、一次撤销/重做、失败回滚与 ID 保持、越界、嵌套拒绝、锁轨、浮点边界和 HDR 拒绝。

同一固定工具链的 `cargo clippy -p concat-project --features schema --lib -- -D warnings` 通过。

已新增但尚未在本单元运行：宿主真实媒体伪装拒绝测试、MCP `tools/list` 实际 schema 暴露测试。它们需要宿主完整依赖编译。
