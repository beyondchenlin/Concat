# BK CAT 第二批乙：原生会话数据库端口与编辑操作日志

日期：2026-11-13。当前独立开发分支 `feature/bk-cat-m2-persistence`。该代码是必须由受控平台宿主调用的安全持久层，并非已经在产品窗口中接通的真实编辑闭环。

## 需求映射和实现

- 功能03、09／验收03、09／任务02、04、10：`src/crates/concat-agent/src/sqlite.rs` 在已经取得会话唯一执行权并完成用户恢复确认后，开放与固定 Pi 1.5.2 兼容的原生数据库驱动。文件名固定、拒绝调用方选路径；浏览器传入的句柄及代次必须逐次核对。读取恢复状态不会初始化或升级数据库。
- 功能07、08、09／验收07、08、09／任务04、10：`src/crates/concat-agent/src/operations.rs` 持久化受信任的原版调用身份、原生编辑意图、原生回执、工程文件落盘哈希和完成通知。未确定结果禁止重放，后续恢复仍需要核对工程／会话／版本并由用户决定。
- 固定原版表结构测试数据来自提交 `d36266e06669c6991a7c9509d1da04d18d30378d`，附带原有版权声明。业务代码未建立另一套会话或智能体调度循环。
- `src/Cargo.lock` 新锁定本批必要的数据库和校验依赖；仅操作项目专有会话目录。原生持久层不连接外部模型、素材服务或收费接口。

## 两轮内部代码审查

1. 存储和恢复语义审查：发现已有数据库可以伪造目标版本但缺真实表，或借助同名视图干扰检查；已要求九张持久化必需表均为普通表，先启用授权器再做元数据检查。新增损坏标记与视图拒绝测试。
2. 数据边界、平台安全和持久化状态审查：发现数据库原生 ID 使用无符号整数不兼容绑定库，并检查文件替身、重解析点、事务失效及四状态转换。已显式限制读写整数转换、拒绝异常文件类型、补充平台重解析路径保护并实际重跑测试。

以上是两轮实际内部源码审查；独立外部代码审查仍待取得。当前既未创建 Windows WebView2／安卓 WebView 真正宿主，也未把 `record_saved` 接入原生窗口的真实 `Saved::Written` 回调，所以绝不把数据库与日志通过称作正式产品验收完成。
