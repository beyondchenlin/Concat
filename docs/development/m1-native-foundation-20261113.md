## 先失败、后修复的证据

1. 初次共享接口回归发现新增受保护编辑请求缺少回执结构映射；补齐后35项接口测试通过。
2. 三项音频导出失败分别在二开树与未修改的v0.2.10（原生基线）复现。视频包按解码顺序到达，最后包并非最大显示终点；原截止点会截短音频。修复取最大值后，新增故障测试及17项原导出回归全部通过，原阈值未改。
3. 协议预览测试曾超时。隔离用户目录缺少标准系统子目录，实际线程栈落在本机图形驱动缓存创建文件循环。只完善测试临时目录后，同一程序完成预览和导出；正式4项端到端测试随后全部通过。未修改驱动、全局缓存或其他项目。
4. 原端到端导出断言只检查“不再运行”，会把失败误记成功；现要求明确完成状态和非空产物，并保留严格递增进度断言。
