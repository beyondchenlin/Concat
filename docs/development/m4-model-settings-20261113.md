## 配置持久化与资格边界

配置只保存非秘密元数据，文件是本产品配置目录下的 `bk-cat/model-settings/model-channels.json`（模型渠道配置）。渠道身份由原生随机生成，更新保持同一身份；配置总版本与单渠道版本随修改递增。保存新渠道不会自动选择，删除当前渠道不会自动选择另一条。

写入使用同目录临时文件、文件同步、原子替换和读回核验；永久锁文件保护同一配置存储的写入者。提交前同时比较预期文档、版本和原文件字节摘要，能拒绝同版本外部改写。读回确认必须同时匹配本次文档和实际写入的同一字节摘要。写入失败、替换后读回错配均不会被记录为保存成功，也不擅自还原外部写入。

读取有大小上限，拒绝未知格式版本、未知字段、秘密或授权字段、重复身份、悬空选择及非规范值。没有迁移工程、智能体会话或已有未知配置。微软桌面系统仅记录已执行的文件同步与读回，不从这些操作推定目录条目在突然掉电后的持久性保证。

服务地址规范化保留协议、主机、有效端口和完整基路径。主机、端口或路径变化都会生成不同凭据作用域，旧密钥不会被默认为新地址的凭据。只有加密地址和本机回环明文地址被配置校验接受；没有域名解析、连接测试、自动重试或模型调用。当前协议字段只接受已经核对固定智能体源码的三个明确协议标识，不把协议支持等同于服务联调通过。

原生设置维护先撤销旧运行资格，后台等待真实平台关闭及所有权释放，再取得同一会话目录的临时独占锁。另一个进程占有该存储时维护拒绝。凭据替换或删除先使配置版本失效；安全存储失败不转成“缺失”，不降级普通文件，界面重新读取实际结果。保存配置、保存凭据、选择渠道和重新读取都不签发联网或费用许可，聊天发送保持禁用。
