# 文案工作区：持久版本与原生界面

日期：2026年11月13日，北京时间。对应需求文档1.1基线的功能04，并涉及功能02、功能08、功能09的原生界面与保存保护。

## 本组解决的问题

原文案入口只保留界面里的临时文本，无法形成独立于聊天记录的版本历史，也没有明确保存用于剪辑的版本。本组将手动文案接到独立持久层和真实原生回调：保存新增不可变版本，选择剪辑版本是另一项明确操作，保存后续稿件不会移动已选版本。

本组是手动文案与版本存储交付。真实模型生成／改写、模型读取所选文案并完成剪辑、安卓真机文案操作、应用进程重启验收仍分别记录，不能由本组测试替代。需求功能04的整组验收尚未通过。

## 已实现行为

- 新建草稿、粘贴和手动编辑，原样保存中文、标点、空格和段落换行。
- 每个工程使用规范化真实工程路径关联独立文案对象；当前支持同一路径重新打开，不承诺移动工程目录后的自动迁移。
- 保存生成不可变版本，可查看历史并明确选择剪辑版本。版本绑定包含工程、文案、版本号和内容摘要；后续保存不会改变该绑定。
- 保存期间继续输入时，保存回执只更新已保存基线，保留新输入。
- 保存失败保留草稿；过期快照明确拒绝，用户可通过“保留草稿并读取”刷新最新保存状态，再明确新增版本。
- 读写期间和存在未保存文案时，普通关闭及切换工程明确拒绝；旧工程回调继续受原有工程代次保护。
- 不可拒绝的正常终止独立收尾文案与原时间线，文案错误不能跳过原工程最后保存。显式选择放弃保存退出保留原语义。
- 生成候选的数据结构、落盘和接受校验已实现。候选到达不覆盖手稿，不自动保存版本或切换剪辑选择；本组未接通实际模型生成入口。

## 数据与并发处理

文案使用产品数据目录中的 `script-versions.sqlite3`（文案版本数据库），与原版智能体会话数据库分开。没有新增智能体调度循环，没有新增依赖或修改依赖锁文件，也没有新增第二份可写时间线。

数据库事务同时提交正文版本与文档修订。保存比较完整旧快照；只有真实事务提交成功后才更新调用者的内存基线。版本和候选由数据库触发器保护为不可变对象，读取时重新核验内容摘要与版本关系。

首次建库先完成本次私有临时库的建表、提交、结构核验、关闭与同步，再用不覆盖已有文件的原子发布安装正式库。中途退出遗留的本次临时文件不会被当作正式库；未知已有空文件、外部数据库、异常对象均拒绝采用，不覆盖修复。

普通关闭允许用户处理未保存内容；不可拒绝终止使用独立路径。工程内的本地文案操作门在终止时关闭，已开始的操作先结束，尚未开始的后台操作被拒绝；随后按当前真实快照保存最后手稿，保持所选剪辑版本。该流程不承诺强杀、断电或存储设备故障时仍能保存内存内容。
