# BK CAT 第二批甲：受控 Pi 浏览器运行组件

日期：2026-11-13；预期独立拉取请求：原版智能体组件与受控浏览器启动、消息边界。本交付 **不** 包含电脑或安卓网页宿主创建，也不是可运行的产品剪辑闭环。

## 代码与需求

- 路径：`src/agent-runtime/`；对应功能03、07、09，验收03、07、09及任务02、04、05、10。
- 固定原始 Pi 提交 `d36266e06669c6991a7c9509d1da04d18d30378d`，版本 1.5.2。构建核对真实原版宿主、模型、持久会话及协议组件都进入浏览器包，禁止静默换到其他版本或纳入 Node、标准输入输出、第二套调度器。
- `AgentRuntime` 生命周期门禁限制原版提交、等待、继续、压缩、取消等调度入口。宿主唯一执行者、恢复批准、事务、网络授权由原生端最终决定；浏览器端门禁不能代替原生独占锁。
- 消息端口绑定受控组件代次、可信原版工具调用身份和原生会话数据库请求，禁止网页直连模型服务或客户端偷偷重试执行。原版组件仍是唯一的模型和持续会话实现。
- `assets/index.html` 使用严格内容安全策略，加载构建所得 `runtime.js`、`bootstrap.js`；平台必须额外提供经来源验证的 `/transport.js`。当前电脑、安卓均尚未创建宿主与实际消息路由；缺配置时明确拒绝模型请求。
- 构建目录 `dist/` 是被忽略的本机生成物；构建还需要本机已核验、锁定提交的只读 Pi 参考工作树。未将未核验脚本发布为安装包。
