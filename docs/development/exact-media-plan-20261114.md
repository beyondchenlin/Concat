# 精确素材剪辑的原生执行边界

本轮在已有原生受控编辑入口内增加精确音视频片段，不创建另一份时间线、撤销历史或任务调度。基点为第 12 号拉取请求的 `62423b97d038907b02e63700bd9dadbd7f43afca`。代码位于独立生产链路开发分支；本记录不构成设备验收。

## 本轮实际改动

新增 `addMediaClipExact`（精确新增媒体片段）命令。素材编号来自当前工程已经导入的素材，轨道必须已经存在。明确指定素材类型、原素材起止和时间线位置，速度固定为正常速度：

```json
{
  "op": "addMediaClipExact",
  "mediaId": "m1",
  "trackId": "T1",
  "kind": "video",
  "start": 4.25,
  "sourceStart": 1.5,
  "sourceEnd": 5.0
}
```

此例在时间线第 4.25 秒放置原素材第 1.5 至 5 秒，片段时长为 3.5 秒。`kind`（素材类型）只接受 `video`（视频）或 `audio`（音频）。未知时长、占位素材、类型不符、越界、目标区间碰撞都会拒绝；拒绝后不会寻找其他空隙。

受保护的文字新增现在要求明确轨道、开始时间和时长。受保护的整组移动要求原生位置解析结果与请求逐项一致；原生手动操作仍保留寻找空隙的原行为。现有原生轨道没有固定类型字段，本轮没有更改工程结构；精确新增要求目标轨道为空，或只包含同种片段。

所有新增、文字和移动继续通过已有事务暂存、当前锁轨检查与原生提交。一个接受的批次只有一个撤销步骤。任意子操作被拒绝，整批、编号分配和撤销重做历史均保持原状。

## 真实素材和最终授权

`Live.apply_guarded`（当前窗口受控编辑）先在原生线程捕获当前工程和版本，随后在后台探测真实素材。路径只能来自已导入素材，网页和模型不能为探测另传路径。后台探测期间持有在途操作计数，不持有所有权互斥锁或界面锁。

`ExactMediaChecks`（精确素材证明）保留实际文件句柄，核对普通文件、原生文件身份、长度、修改时间、真实音视频流与实际时长。探测前后检查撤权。最终编辑回调再检查当前导入记录和文件身份，再由现有原生编辑器执行版本及锁轨校验。

最终回调调用 `embedded::validate_current_edit`（当前任务与文案选版校验）。生产组件须将编辑绑定到原生捕获的持久工程身份、打开会话、工程版本和明确选定的不可变文案；模型参数不提供文案授权。该最终校验不能重新进入所有权锁或执行磁盘探测。

文件前后核对不是不可变字节快照；本轮没有宣称可抵御外部进程对同一文件内容和时间戳的任意恢复。碰撞判断沿用原生已有的百万分之一秒浮点邻接容差。

## 当前范围

本轮精确执行面向已经导入的本地音视频和已有轨道。没有新增自动建轨、素材检索、服务器素材、配音服务或静态图片的精确添加接口。模型生成完整短片模板、最新双端安装启动、真实视频导出仍须各自取得对应证据。

原生编辑器首次加入高动态范围素材时会联动时间线设置；已有受控边界拒绝片段范围以外的变化，本轮没有放宽该限制。不能将普通本地音频的回归结果外推为所有视频格式已验证。
