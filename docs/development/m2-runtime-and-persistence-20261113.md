# BK CAT 第二批开发：受控运行组件、持久化端口与原生聊天布局

日期：2026-11-13。分支：`feature/bk-cat-m1-runtime`。本记录为阶段性源码交付的可复核证据，不是产品验收通过证明。

## 对应需求与实际代码

- 功能02、03、07、09／验收02、03、07、09／任务02、04、05、10：`src/agent-runtime/` 接入固定提交 `d36266e06669c6991a7c9509d1da04d18d30378d` 的原版 Pi 1.5.2 宿主、持久会话、模型和协议组件；宿主所有调度入口受生命周期门禁限制。没有自造任务调度循环。尚未配置模型渠道、预算或真实流式传输。
- 功能03、09／验收09：`src/crates/concat-agent/src/sqlite.rs` 通过原生所有权代次提供受限数据库端口，复用 Pi 1.5.2 的真实表结构；仅核对不打开可写会话，明确用户批准后才可初始化空存储。事务与退出时的回滚受原生宿主约束。
- 功能07、08、09／验收07、08、09：`src/crates/concat-agent/src/operations.rs` 独立保存原生编辑意图、真实编辑回执、工程文件哈希和已送达完成通知。重复、未确定结果及交接异常均拒绝自动重放。完整生产调用链尚未接入；四个子进程故障测试仅是数据库记录层的确定性测试，不替代完整应用的四断点验收。
- 功能02、07／验收02、07：`src/crates/concat/ui/agent.slint`、`src/crates/concat/ui/workspace/agent-workspace.slint`、`src/crates/concat/src/panes/agent.rs` 及窗口接线提供电脑项目／聊天／原生预览布局和手机单栏聊天／预览入口。手动编辑仍使用同一个原生工程；没有复制一条可写时间线。缺少真实宿主、模型和预算时发送不可用，草稿不伪装成已发送消息。
- 浏览器分发资源由 `npm run build` 产生：`dist/index.html`、`runtime.js`、`bootstrap.js` 及原始许可、组件清单。网页明确要求平台提供受控 `/transport.js`；Windows WebView2、安卓 WebView 的实际创建及原生消息接线尚未实现，不能视为双端共存通过。

## 两轮源码检查与已处理问题

1. 结构及安全检查：检查存储所有权、事务代次、异常交接、旧意图去重和锁轨边界。发现已有库可伪造版本标记而缺少所需表、同名视图干扰检查、数据库记录 ID 类型与绑定库不兼容；已补充九张必需表类型核验、禁止视图执行，并将操作日志 ID 转为带边界检查的有符号持久化类型。独立子进程与异常恢复测试随后重新运行。
2. 构建及接口检查：发现原生聊天布局有尺寸依赖环、电脑上运行组件目录缺少最新消息封装和网页入口、初次新环境验证未带媒体库路径。已解除尺寸依赖环、同步真实网页入口与脚本、用正确的已安装媒体库环境重跑构建。仍未接入平台网页宿主，因此不宣称真实协议到原生编辑已闭环。

两轮均是本阶段开发内部实际检查；**独立审查者对完整第二批代码的正式审查尚未取得**。不能用本文件替代独立审查结论。
