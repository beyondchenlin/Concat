# 第三批甲：原生存储停止、保存证据和拒绝终态

日期：2026-11-13。源码基点：`fb85eb72086e29e71c8ff6a5dbfb0f2de494477c`。本组是在现有1.1开发基线上的代码修补；完整产品验收仍未执行。

## 问题与实际修改

1. 生产数据库桥的一条合法隔离聚合查询运行4,060毫秒，原同步撤权等待4,029毫秒。增加不可复位的快速停止请求和无须取得写锁的状态快照；新准入在锁前、锁后检查停止，数据库实际执行的进度回调响应停止。既有同步副作用临界区仍保留，已进入的操作真实完成或回滚以后才交接。本组提供原生核心入口，应用窗口的调用接线属于依赖本组的平台宿主交付。
2. 只读数据库核对与文件证据读取不再在长时间持有所有权锁的情况下执行。读取前后检查原代次；迟到结果不能授予执行资格。
3. 保存回执与编辑回执按同一工程、会话及版本汇合。保存先到的候选仅在本代内存中保存；随后匹配真实编辑回执才写入既有保存列。对文件的文档比对与散列来自同一份读取结果。
4. 原生执行端已经证明没有修改的拒绝及零变化成功结果，使用明确终态，避免正常锁轨拒绝永久形成未知操作。未知或已修改但缺回执的结果继续待核对并撤销后续准入。
5. 只发送当前代次的待确认保存结果。旧通知不能在重开后自动送达或自动确认；完整网页收件确认接线属于平台宿主交付。

对应需求：功能03、07、08、09；验收03、07、08、09；任务02、03、04、10。没有更换固定上游、原版智能体版本或编辑核心。

## 数据与执行边界

- 原版持久会话表结构保持版本2；既有不兼容结构仍拒绝打开，不自动迁移。
- 操作日志仍使用原记录表及13列，没有新增表、列或改写既有记录。保存候选不会跨进程存活。
- 快速停止阻断后续准入；已经提交的修改不会因停止被撤销。磁盘同步不承诺即时中断。
- 数据库关闭并不等于可以接管。旧许可未排空或尚未完成明确交接时，操作系统独占锁继续保留。
- 仅固定原生回滚路径允许停止后的清理；页面不能借助清理标记执行其他语句。
