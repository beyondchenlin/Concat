### 6.2 G1纯镜像与前置收敛

纯镜像用upstream-mirror，不使用本地main或origin/main。镜像当前不存在；先检查实际分支、关联工作区和目标。不存在则创建；存在则须属于官方历史且是目标祖先，才可快进。两种路径二选一，工作区需安全且无占用；禁止向任何远端推送镜像，所有推送指定目标与产品分支/标签，不使用 --all 或 --mirror。

```powershell
git show-ref --verify refs/heads/upstream-mirror
# 仅确认不存在时：
git branch upstream-mirror $target
# 仅已存在、确认可快进且工作区安全时：
git merge-base --is-ancestor refs/heads/upstream-mirror $target
git switch upstream-mirror
git merge --ff-only $target
git switch dev
git rev-parse refs/heads/upstream-mirror
```

镜像必须等于$target，失败停止。确认隔离目录/分支未占用及磁盘足够。使用冻结$own建立临时工作区。rerere仓库级配置由关联工作区共享；执行前记录原值，核对是否存在worktree级覆盖，获授权后持久设置并验证实际生效，不改全局配置。若其他工作区正在合并/配置有冲突，先协调。

```powershell
$sync = 'sync/upstream-20261125-desktop'
$work = 'D:\BK-CAT-sync-20261125'
git worktree list
git branch --list $sync
Test-Path -LiteralPath $work
# 仅确认均未占用后：
git worktree add -b $sync $work $own
git -C $work config --show-origin --get rerere.enabled
git -C $work config --show-origin --get rerere.autoupdate
git -C $work config --local rerere.enabled true
git -C $work config --local rerere.autoupdate false
git -C $work config --show-origin --get rerere.enabled
git -C $work config --show-origin --get rerere.autoupdate
```

有效值必须true/false；若原值不存在查询退出1可记录为未配置；其他异常或工作区覆盖导致不一致则停止核查。持久配置跨解决冲突和提交生效。G1完成B02/B03/B04/B05等对应任务，先逐键提取并验证自有词条及必要覆盖，再按L01a恢复共同祖先已有原词库，不能直接复制目标词库。等价验证通过后在隔离分支以独立提交记录前置修改；不在本文件给出未经差异审查的批量恢复命令。记录前置提交$prep及真实祖先，确保工作区干净。
