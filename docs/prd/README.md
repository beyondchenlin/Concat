## 当前开发基线

[1.3.2版完整产品需求文档](bk-cut-20261123/PRD.md)，日期：2026年11月24日。

正式品牌和标志按用户最新确认统一为 BK CUT（智能剪辑软件，全大写，中间一个空格），沿用原图图形、绿色配色和原有文字。本版继承原九项功能，补充品牌、多语言、模型服务与低门槛新建工程的七项已确认调整；包含46项新增验收及12项实施任务。

已重新完成用户要求的两轮作者文档自查，第一轮10项问题均已修订并复核关闭，第二轮未发现阻断项。问题、修订及对应验收记录在第16章。

产品行为以1.3.2版及继承条款为准，专项同步架构/阶段/身份/迁移及门禁以1.3版为准；未修改的原有要求继续有效。11月24日实机反馈明确双端启动保留项目首页，新建跳过参数表单，取消普通回复语言限制，模型供应商进入同一设置导航并全量本地化，升级后核查实际启动图标；产品实现和全部验收仍以实际提交、测试和安装证据为准。
